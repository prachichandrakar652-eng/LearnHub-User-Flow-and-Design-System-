# LearnHub – User Flow & Design System

This repository contains the UX planning and design system for LearnHub, an online learning platform UI/UX project designed in Figma.

## Overview

The project focuses on establishing a clear user journey and a consistent visual design system before developing the final high-fidelity interface.

## Contents

### User Flow

The user flow maps the complete learning journey through the platform:

Splash → Login → Sign Up → Home → Search Results → Course Details → Enrollment Confirmation → Course Player → Quiz → Quiz Result → Course Completion → Certificate

Additional navigation includes:

Home → Profile  
Home → Settings

### Design System

The design system defines the reusable visual elements used throughout the LearnHub interface, including:

- Color Palette
- Typography
- Buttons
- Cards
- Input Fields
- Navigation Components
- UI Components
- Spacing and Visual Consistency

## Design Process

1. User Flow

4. High-Fidelity UI
